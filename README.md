# PCA - Multivariate Analysis

Four independent PCA exercises for Multivariate Statistics.

## Sections
1. Exercise 5.7 - Stock-price data
2. Exercise 5.8 - PCA and measurement units
3. Exercise 5.11 - Food-security data
4. La Liga - Football performance statistics

Open `PCA-Multivariate-Analysis.Rproj` in RStudio, run `source("packages.R")`, and edit the `.Rmd` files under `exercises/`.

The `data/` directory holds source datasets. Generated plots and tables belong in `outputs/`.

## Shared setup

Run `source("packages.R")` once to install packages. All Rmd files load `R/setup.R` for common PCA libraries and formatting helpers. Open the `.Rproj` file before knitting.
